## 01. Brand & Core Philosophy

**AKARI STUDIOS** is an independent creative, technology and digital growth agency rooted in Tokyo with operations worldwide.

The digital experience is built upon:
- **Expressive Brutalism**: Raw, asymmetric grids, sharp corners, and intentional tension.
- **Editorial Art Direction**: Unapologetic typography scale, high-impact culinary and architectural photography.
- **Tactile Motion & Performance**: 60fps micro-interactions, Lenis smooth scrolling, GSAP ScrollTrigger, and subtle Web Audio feedback.

## 03. Design System & Tokens

### Color Palette
- **Warm Cream**: `#F4EBDD` (Primary light canvas)
- **Akari Vermilion**: `#C83E17` (Signature brand accent & Japanese seal)
- **Ink Black**: `#211B18` (High-contrast typography & dark sections)
- **Muted Gold**: `#B59A69` (Secondary luxury accents)
- **Pure White**: `#FFFFFF` (High contrast elements)

### Typography Hierarchy
- **Primary Display**: `Anton` (Heavy condensed display for hero, oversized statements, section headers)
- **Secondary**: `Space Grotesk` (Geometric, contemporary for navigation, tags, subtitles, buttons, metadata)
- **Body**: `DM Sans` (Clean, readable for paragraphs and case studies)
- **Calligraphy / Seal**: `Noto Serif JP` (朱 - Inkan seal)

---

## 04. Technical Architecture

- **Core**: React 19 + Vite
- **Styling**: Tailwind CSS v3 + PostCSS + Custom Brutalist Design System
- **Animation & Motion**: GSAP + ScrollTrigger + Framer Motion
- **Smooth Scroll**: Lenis
- **Routing**: React Router v7 (`/`, `/work`, `/services`, `/about`, `/contact`)
- **Icons**: Lucide React
- **Audio Feedback**: Self-contained Web Audio API synthesizer for tactile interface clicks and stamp audio

---

## 05. Key Features

- **Preloader**: Brutalist percentage counter with kinetic unboxing and vermilion seal stamp reveal.
- **Dynamic Header**: Live Tokyo JST clock, operational status indicator, and sound feedback toggle.
- **Interactive Growth Simulator**: Real-time ROI and commercial upside calculator for restaurant owners and property developers.
- **Case Study Drawer**: Interactive deep-dive modal displaying verified commercial metrics, client challenges, solutions, and deliverables.
- **Intake & Briefing Modal**: Scoped multi-step intake with sector selection, budget tiers, and bilateral NDA guarantee.
- **Custom Brutalist Cursor**: Responsive follower with dynamic "VIEW" and "DRAG" contextual states.
